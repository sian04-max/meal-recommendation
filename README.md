# 🍽️ 식사 메뉴 랜덤 추천기 (Meal Recommendation Service)

> 복잡한 고민 없이 **아침 / 점심 / 저녁**만 고르면, OpenAI AI가 한국인의 입맛에 꼭 맞는 **메인 메뉴 1개와 최적의 꿀조합 메뉴 1개**를 세트로 추천해 주는 웹 서비스입니다.

---

## 🌟 주요 기능
1. **식사 시간대별 AI 메뉴 추천**: 아침 / 점심 / 저녁 선택에 따른 찰떡궁합 2종 메뉴 및 추천 이유 제공
2. **비회원 실시간 피드백**: 회원가입 없이 누구나 한마디를 남길 수 있고, Supabase DB에 저장되어 최신순 목록으로 즉시 노출
3. **직관적인 카드형 UI**: 누구나 쓰기 쉬운 웜톤의 깔끔하고 반응형 레이아웃
4. **Vercel 원클릭 배포 지원**: 서버리스 함수 및 정적 웹 완벽 호환

---

## 🚀 로컬 실행 방법

```powershell
# 1. 프로젝트 폴더로 이동
cd C:\Users\USER\Desktop\meal-recommendation

# 2. 패키지 설치 (최초 1회)
npm install

# 3. 서버 구동
node server.js
```

브라우저에서 `http://localhost:3000` 접속!
