# 04-database-supabase.md - Supabase DB 스키마 및 피드백 구현 지침

## 1. SQL 테이블 생성 스키마
```sql
CREATE TABLE public.feedbacks (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  nickname TEXT DEFAULT '익명',
  content TEXT NOT NULL,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);
```

## 2. RLS(Row Level Security) 설정
```sql
ALTER TABLE public.feedbacks ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Anyone can read feedbacks" ON public.feedbacks FOR SELECT USING (true);
CREATE POLICY "Anyone can insert feedback" ON public.feedbacks FOR INSERT WITH CHECK (true);
```
