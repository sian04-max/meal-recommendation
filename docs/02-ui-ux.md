# 02-ui-ux.md - UI/UX 및 HTML/CSS 구현 지침

## 1. 디자인 컨셉
- 남녀노소 누구나 사용하기 쉬운 **직관적이고 깔끔한 UI**
- 시각적 가독성이 높은 카드 형태의 레이아웃
- 따뜻하고 식욕을 돋우는 은은한 컬러 팔레트 (웜 톤 오렌지/베이지 계열 포인트)

## 2. 주요 UI 구성 요소를 단일 화면에 배치
1. **헤더**: 서비스 제목 및 간단한 설명
2. **메뉴 추천 섹션**:
   - 아침 / 점심 / 저녁 선택 라디오 버튼/드롭다운
   - "메뉴 추천받기" 버튼
   - 결과 카드 (추천 메인 메뉴 1개 + 최적 조합 메뉴 1개 + 추천 이유)
3. **오류 메시지 영역**: 에러 시 빨간색 안내 상자 표시
4. **피드백 섹션**:
   - 닉네임 및 피드백 입력 폼 + 전송 버튼
   - 피드백 목록 (최신순 리스트)
